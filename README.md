# Smart Utility Toolkit

Lab Assignment 1 for Web Dev III (Node.js & Express Backend).

## Run

Calculator:
node calculator.js add 10 5

Custom modules:
node app.js

HTTP server:
node server.js

File manager:
node fileManager.js

Dice generator:
node dice.js 5

## Requirements

Node.js only. No external npm packages are required.
